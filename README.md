# PAC-5---Veteran
Projeto extensionista PAC5


##Atividade em desenvolvimento
O projeto tem o objetivo atender um club de carros antigos na cidade de Joinville - SC.

O Club atualmente não possui um sistema de controle e gerenciamento das atividades, fluxo de caixa, registro de membros.
A ideia é gerir um sistema de controle básico para o club.
